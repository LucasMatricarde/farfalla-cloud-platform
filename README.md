# Farfalla Cloud Platform

GitOps deployment of the **ERP-Farfalla** application on AWS. Terraform provisions
the infrastructure, a single-node **k3s** cluster runs the workloads, **ArgoCD**
keeps the cluster in sync with this repo, and **GitHub Actions** builds images and
bumps deploy tags. TLS, ingress, and observability are wired in.

> **v1 scope:** single node, single environment (`prod`), no autoscaling.
> Future: EKS, multi-env, HPA, canary, Datadog.

## Five pillars (what each part actually does)

### 1. Infrastructure as Code — `terraform/`

Everything in AWS is declared in Terraform. The root module under
`terraform/envs/prod` composes four reusable modules:

| Module | Real function |
|---|---|
| `modules/network` | Builds the VPC: 1 public subnet (k3s node) + 2 private subnets (RDS, multi-AZ subnet group). Internet Gateway + public route table give the node ingress/egress. Two security groups: **ec2-sg** (SSH + k3s API `6443` locked to your IP; `80/443` open to the world) and **rds-sg** (Postgres `5432` reachable *only* from the ec2-sg — DB never faces the internet). |
| `modules/ec2-k3s` | Launches one Ubuntu 24.04 EC2, attaches an **Elastic IP** (stable address) and an **instance profile** with `AmazonEC2ContainerRegistryReadOnly` so the node pulls images from ECR without keys. `user_data.sh.tftpl` installs k3s on boot with the EIP baked into the API TLS SAN, and writes an EIP-rewritten kubeconfig to `/home/ubuntu`. |
| `modules/rds` | PostgreSQL instance, private only, gp3 storage. Password generated by `random_password` and exposed as a sensitive Terraform output (never hardcoded). |
| `modules/ecr` | Two image repos (`farfalla-backend`, `farfalla-frontend`) with scan-on-push and a lifecycle policy that expires all but the last 10 images. |
| `envs/prod` (root) | Wires the modules together **and** defines the **GitHub OIDC CD role** (`farfalla-github-cd`): a federated IAM role GitHub Actions assumes via OIDC (no long-lived keys), scoped to push only to these ECR repos and trusted only from `repo:<github_repo>:*`. |

State lives in S3 with DynamoDB locking — provisioned separately by
`terraform/state-backend` (bootstrapped with local state, then everything else
uses the S3 backend).

### 2. Kubernetes runtime — k3s

A lightweight single-binary Kubernetes (k3s) on one EC2. Ships with **Traefik**
as the built-in ingress controller. The node's API-server certificate is valid
for the Elastic IP, so a remote `kubectl` works straight from the rewritten
kubeconfig (`scripts/fetch-kubeconfig.sh`).

### 3. GitOps delivery — `k8s/` + ArgoCD

The cluster's desired state *is* this Git repo. ArgoCD runs the **app-of-apps**
pattern (`k8s/bootstrap/app-of-apps.yaml`):

- **app-of-apps** → deploys the platform Applications (cert-manager, kube-prometheus-stack, Loki).
- **farfalla-app** → deploys the application manifests in `k8s/apps/farfalla`.

Both use `automated` sync with `prune` + `selfHeal`: drift is corrected
automatically and removed resources are pruned. `scripts/install-argocd.sh`
installs ArgoCD; `scripts/bootstrap-cluster.sh` applies the AppProject +
app-of-apps once.

`k8s/apps/farfalla` (rendered by Kustomize) contains:
- **backend** Deployment (Spring Boot, port 8080, `/actuator/health` probes, config from ConfigMap + secret), Service, and a Prometheus **ServiceMonitor**.
- **frontend** Deployment + Service (port 80).
- **Traefik IngressRoute**: routes `/api`, `/actuator`, `/swagger-ui`, `/v3/api-docs` to the backend, everything else to the frontend — same host, over HTTPS.
- **cert-manager Certificate** + ClusterIssuer for automatic Let's Encrypt TLS.

The DB password is **not** in Git — it's created as `backend-secret` out-of-band
from the Terraform RDS output (runbook §6).

### 4. CI / CD — `.github/workflows/`

**CI (`ci.yml`, on PR to main)** — gatekeeper, no deploy:
- `terraform fmt -check` + `terraform validate` on the infra.
- Renders `k8s/apps/farfalla` with Kustomize and validates all manifests with `kubeconform`.
- Checks out the **app repo** and runs `mvn verify` (Java 21 backend) + `npm ci && npm run build` (frontend).

**CD (`cd.yml`, on push to main)** — build + ship:
1. Assumes the AWS CD role via **OIDC** (no stored credentials).
2. Builds backend (`--target prod`) and frontend Docker images from the app repo, pushes to ECR tagged with the commit SHA.
3. Runs `kustomize edit set image` to bump the tags in `k8s/apps/farfalla/kustomization.yaml`, then commits the bump back to main.
4. ArgoCD sees the changed manifest and rolls out the new images.

A guard (`if: github.actor != 'github-actions[bot]'`) stops the bump commit from
re-triggering CD. `concurrency` serializes runs.

### 5. Observability — `k8s/platform/`

Deployed as ArgoCD Applications pulling upstream Helm charts:
- **kube-prometheus-stack** — Prometheus (7-day retention, scrapes the backend via ServiceMonitor), Grafana (exposed through Traefik), Alertmanager.
- **Loki** — log aggregation.
- **cert-manager** — issues/renews Let's Encrypt certs for the ingress hosts.

Hostnames use **sslip.io** (`<EIP-with-dashes>.sslip.io` resolves to the EIP) —
free DNS so Let's Encrypt HTTP-01 can validate without buying a domain.

## Deploy

Full zero-to-running procedure is in **`docs/runbook.md`**. Summary:

1. `terraform/state-backend` → `apply` (creates S3 + DynamoDB).
2. Create the GitHub OIDC provider (once per account).
3. `terraform/envs/prod` → fill `terraform.tfvars`, `apply` (VPC, EC2/k3s, RDS, ECR, CD role).
4. Substitute `__PLACEHOLDER__` tokens in the manifests (hosts, repo URL, ECR repos, ACME email), commit to main.
5. Set GitHub repo variables: `APP_REPO`, `APP_REF`, `CD_ROLE_ARN`.
6. Fetch kubeconfig → install ArgoCD → create `backend-secret` → bootstrap app-of-apps.
7. Verify: ArgoCD all Synced/Healthy, `https://app.<EIP>.sslip.io` loads with valid TLS, Grafana dashboards populate.

**Teardown:** delete the app-of-apps, then `terraform destroy` (prod, then state-backend).

## Validation without deploying

The whole platform was validated read-only (no `apply`, no running cost):

```bash
terraform fmt -check -recursive terraform
terraform -chdir=terraform/envs/prod validate
kustomize build k8s/apps/farfalla        # 10 resources
terraform plan                            # state-backend: 5 to add · prod: 24 to add
```

The only persistent AWS resource so far is the GitHub OIDC provider (free,
prerequisite for the CD role).
